## Download All Experts

```bash

python scripts/download_datasets.py --list-experts

# Download all (120+ datasets)
python scripts/download_datasets.py --expert all

# Download specific category
python scripts/download_datasets.py --expert python
python scripts/download_datasets.py --expert react
python scripts/download_datasets.py --expert healthcare
```

---

## Train All Experts

```bash
# Train single expert
python scripts/train_expert.py --expert python

# Train multiple (in loop or parallel)
for expert in python javascript java react fastapi; do
  python scripts/train_expert.py --expert $expert &
done
wait
```

---

## Compile Experts

```bash
# Compile single expert
python scripts/compile_to_khanary.py \
  --checkpoint checkpoints/python_final \
  --output experts/python.khμ \
  --expert-name python

# Compile all
for expert in python javascript java react fastapi; do
  python scripts/compile_to_khanary.py \
    --checkpoint checkpoints/${expert}_final \
    --output experts/${expert}.khμ \
    --expert-name $expert &
done
wait
```
